# 🌙 Sleep Compass

> **A data-driven sleep assessment app developed with Python and Streamlit**

Sleep Compass は、睡眠習慣に関する質問から睡眠タイプを診断し、
睡眠スコアや改善ポイントを分かりやすく可視化するWebアプリです。

---

## 📌 Features

- 🐧 4つの睡眠タイプ診断
- 🌙 Sleep Score（100点満点）
- 📊 レーダーチャートによる可視化
- 💡 タイプ別アドバイス
- 📈 平均との比較表示

---

## 🛠 Tech Stack

- Python
- Streamlit
- NumPy
- Plotly

---

## 📊 Analysis

This application is based on cluster analysis of **154 anonymous sleep questionnaires**.

The original questionnaire data is **not included** in this repository.
Only statistical information and cluster centers are used for the diagnosis.
